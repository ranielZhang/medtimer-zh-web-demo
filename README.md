# MedTimer 中文微信小程序演示

把开源 Android 应用 [MedTimer](https://github.com/Futsch1/medTimer) 的主要界面和用药事件流程移植成微信小程序原生项目（WXML、WXSS、JavaScript）。[在线手机预览](https://ranielzhang.github.io/medtimer-zh-web-demo/) 与小程序共用一份领域模型；预览可操作，但它是网页，并非微信发布的小程序。

## 运行小程序

1. 安装微信开发者工具，选择「导入项目」，项目目录指向本仓库根目录。
2. `project.config.json` 的 `touristappid` 用于本地体验；若要真机预览或发布，把 `appid` 改为自己的小程序 AppID。
3. 在模拟器中依次体验「主页 / 药品 / 分析」。数据仅保存在本机微信存储。右上角菜单可重置虚构数据。

网页预览在本地运行：`python3 -m http.server 8765`，打开 `http://localhost:8765`。也可以直接打开 `standalone-demo.html`。网页与小程序各自保存数据，不会相互同步。

## 已有交互

- 主页：周日期切换、状态筛选、按时序展示提醒；点左侧状态可确认服用、跳过、模拟触发或延后 10 分钟；可补记服药。
- 药品：新增、编辑、删除药品，管理库存、单位、低库存阈值与标签；每种药品可配置多条每周或周期提醒规则。
- 分析：近 7 / 30 天处理结果图、历史表格、月历；记录与库存按服用事件同步更新。
- 核心逻辑：提醒规则生成每日事件；延后保留同一事件；确认服用扣库存、跳过不扣；改判时返还或扣减相应库存。

[界面与逻辑映射、实现边界](docs/product-model.md)。示例均为虚构数据；请勿把演示用作真实服药提醒。小程序只有打开期间计算到点状态，未接入后台定时服务或微信订阅消息，因此不能保证关闭后提醒。

运行完整模型与数据场景测试：`node --test miniprogram/tests/*.test.js`。测试覆盖每周与周期规则、事件触发和延后、服用/跳过及改判、库存边界、补记、分析统计和药品删除后的历史快照。本项目参考 MedTimer 的 UI 结构与领域流程，原项目采用 MIT 许可证；移植代码为独立实现。
