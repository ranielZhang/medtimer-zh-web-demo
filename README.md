# MedTimer 中文版｜微信小程序与交互预览

这是一个面向中文用户的用药管理交互演示项目，参考开源 Android 应用 [MedTimer](https://github.com/Futsch1/medTimer)，以独立实现呈现其核心界面、用药事件流程和记录分析。项目包含可导入微信开发者工具的原生小程序（WXML、WXSS、JavaScript），以及[可交互网页预览](https://ranielzhang.github.io/medtimer-zh-web-demo/)；两端共用领域模型。网页另提供[家庭组双手机联动演示](https://ranielzhang.github.io/medtimer-zh-web-demo/family-demo.html)，可并排体验家人端与长辈端。

演示支持药品与提醒规则管理、服药/跳过/延后/补记、库存变化，以及近 7 / 30 天图表、历史表格、月历和相对浓度趋势。数据为本地虚构测试数据，网页预览不是已发布的微信小程序；项目不提供后台定时提醒，也不构成医疗建议。

## 运行小程序

1. 安装微信开发者工具，选择「导入项目」，项目目录指向本仓库根目录。
2. `project.config.json` 的 `touristappid` 用于本地体验；若要真机预览或发布，把 `appid` 改为自己的小程序 AppID。
3. 在模拟器中依次体验「主页 / 药品 / 分析」。数据仅保存在本机微信存储。右上角菜单可重置虚构数据。

网页预览在本地运行：`python3 -m http.server 8765`，打开 `http://localhost:8765`。也可以直接打开 `standalone-demo.html`。网页与小程序各自保存数据，不会相互同步。

## 已有交互

- 导航：主页、药品、分析、我的四个底部页面；「我的」集中显示本机账户状态、用药数据概览和家庭组入口。
- 主页：周日期切换、状态筛选、按时序展示提醒；点左侧状态可确认服用、跳过、模拟触发或延后 10 分钟；可补记服药。
- 药品：新增、编辑、删除药品，管理库存、单位、低库存阈值与标签；每种药品可配置多条每周或周期提醒规则。
- 分析：近 7 / 30 天处理结果图、历史表格、月历和相对浓度趋势；初始虚构演示数据覆盖最近 30 天，便于查看各视图。药品可选填写半衰期与达峰时间，曲线基于已记录的服用事件做简化估算。它不代表真实血药浓度，也不构成医疗建议。
- 家庭组：从「我的」或右上角菜单进入，可创建 6 位随机邀请码或输入邀请码加入，并查看演示成员信息。家庭组双手机页面中，家人端可为奶奶设置用药安排、查看今日状态和近期记录；奶奶端可处理提醒。两端在同一浏览器中联动；真实跨设备邀请验证与数据同步仍需服务端。
- 核心逻辑：提醒规则生成每日事件；延后保留同一事件；确认服用扣库存、跳过不扣；改判时返还或扣减相应库存。

[界面与逻辑映射、实现边界](docs/product-model.md)。示例均为虚构数据；请勿把演示用作真实服药提醒。小程序只有打开期间计算到点状态，未接入后台定时服务或微信订阅消息，因此不能保证关闭后提醒。

药品用量按 0.5 单位递增，补记与提醒规则都会校验（如 0.5、1、1.5）。运行完整模型与数据场景测试：`node --test miniprogram/tests/*.test.js`。测试覆盖每周与周期规则、事件触发和延后、服用/跳过及改判、库存边界、补记、用量步进、分析统计和药品删除后的历史快照。本项目参考 MedTimer 的 UI 结构与领域流程，原项目采用 MIT 许可证；移植代码为独立实现。
